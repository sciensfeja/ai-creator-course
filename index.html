Детальное описание уроков

Урок 1.1: Синтаксис Python

⏱ 2 часа 📗 Начальный

Переменные, циклы, функции, структуры данных. Первые программы и знакомство с VS Code.

  • Переменные и типы данных
  • Условия и циклы
  • Функции и модули
  • Списки, словари, множества

Урок 1.2: Основы ООП

⏱ 2 часа 📗 Начальный

Классы и объекты на примере создания простой игры.

Урок 1.3: NumPy и матрицы

⏱ 2 часа 📘 Средний

Векторы и матрицы. Связь с геометрией и будущей математикой нейросетей.

Урок 1.4: Pandas и таблицы

⏱ 3 часа 📘 Средний

Работа с таблицами, загрузка CSV, фильтрация и группировка данных.

Урок 1.5: Визуализация данных

⏱ 2 часа 📘 Средний

Matplotlib и Seaborn. Построение красивых графиков для проекта.

Урок 2.1: Математический минимум

⏱ 3 часа 📙 Продвинутый

Производные, линейная алгебра и теория вероятностей «на пальцах».

Урок 2.2: Линейная регрессия

⏱ 3 часа 📘 Средний

Первый алгоритм ML. Scikit-Learn. Предсказание цен на жилье.

Урок 2.3: Деревья решений

⏱ 3 часа 📘 Средний

Random Forest и классификация. Kaggle-соревнование «Титаник».

Урок 2.4: Метрики качества

⏱ 2 часа 📘 Средний

Accuracy, Precision, Recall, F1. Почему 99% точности — это не всегда хорошо.

Урок 3.1: Перцептрон

⏱ 2 часа 📙 Продвинутый

Биологический нейрон vs искусственный. Первый нейрон на Python.

Урок 3.2: Функции активации

⏱ 2 часа 📙 Продвинутый

ReLU, Sigmoid, Softmax. Зачем они нужны и как работают.

Урок 3.3: Backpropagation

⏱ 3 часа 📙 Продвинутый

Как сеть учится? Обратное распространение ошибки на пальцах.

Урок 3.4: PyTorch

⏱ 4 часа 📙 Продвинутый

Знакомство с фреймворком. Тензоры, автодифференцирование, первая сеть.

Урок 3.5: CNN и компьютерное зрение

⏱ 4 часа 📙 Продвинутый

Сверточные сети. Распознавание MNIST и жестов через веб-камеру.

Урок 4.1: Transfer Learning

⏱ 3 часа 📙 Продвинутый

Используем предобученные сети для распознавания своих объектов.

Урок 4.2: Токенизация и эмбеддинги

⏱ 3 часа 📙 Продвинутый

Как компьютер понимает смысл слов. Word2Vec.

Урок 4.3: Анализ тональности

⏱ 3 часа 📙 Продвинутый

Telegram-бот, который анализирует комментарии и банит за токсичность.

Урок 5.1: Трансформеры и Attention

⏱ 3 часа 📕 Экспертный

Как работают большие языковые модели. Механизм внимания.

Урок 5.2: Prompt Engineering

⏱ 2 часа 📘 Средний

Искусство правильно ставить задачу ИИ. Few-shot, chain-of-thought.

Урок 5.3: Работа с API

⏱ 3 часа 📘 Средний

OpenAI, YandexGPT, локальные модели через Ollama.

Урок 5.4: RAG

⏱ 4 часа 📕 Экспертный

Retrieval-Augmented Generation. ИИ отвечает по вашим документам без галлюцинаций.

Урок 5.5: Этика ИИ

⏱ 2 часа 📗 Начальный

Дипфейки, авторское право, предвзятость алгоритмов, влияние на рынок труда.

Урок 6.1: Git и GitHub

⏱ 2 часа 📘 Средний

Версионирование кода. Красивый README для портфолио.

Урок 6.2: Командная работа

⏱ 2 часа 📘 Средний

Разделение ролей: Data Scientist, ML Engineer, Product Manager.

Урок 6.3: Защита проекта

⏱ 3 часа 📕 Экспертный

Питч перед жюри. Финальный хакатон и презентация ИИ-стартапа.
