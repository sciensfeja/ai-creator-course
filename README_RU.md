## 🛠 Практика через GitHub

Вся практическая работа в курсе выполняется на платформе **GitHub**. Это не просто хранилище кода — это инструмент, который используют все профессиональные разработчики и команды по всему миру.

### Что вы освоите:

- ✅ **Git** — система контроля версий: как сохранять изменения в коде и откатываться назад
- ✅ **GitHub** — платформа для хранения и совместной работы над кодом
- ✅ **Pull Request (PR)** — система отправки работ на проверку учителю
- ✅ **Code Review** — процесс проверки кода преподавателем с обратной связью
- ✅ **Ветвление (Branching)** — работа над задачами без риска сломать основной код
- ✅ **Командная работа** — совместная разработка одного проекта несколькими людьми

---

##  Как отправлять работы на проверку

Система отправки домашних работ работает через **Pull Request (PR)** — это стандартный механизм в мире разработки, когда вы предлагаете свои изменения кода на проверку.

### Пошаговый процесс:
Форкните репозиторий курса
↓
Создайте ветку под свой урок (например: lesson-1.1)
↓
Выполните задание и закоммитьте изменения
↓
Откройте Pull Request в основной репозиторий
↓
Преподаватель проведёт Code Review и оставит комментарии
↓
Внесите правки (если нужно) и получите апрув ✅
