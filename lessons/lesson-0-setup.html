Установка и настройка VS Code

Прежде чем создавать нейросети, нужно подготовить рабочее место. Этот урок — ваш пропуск в мир профессиональной разработки.

⏱ 1.5 часа 📗 Для начинающих 🛠 VS Code + Python

🎯 Цели урока

  • Установить Visual Studio Code — главный инструмент разработчика
  • Установить Python и настроить окружение
  • Поставить нужные расширения (Python, Jupyter)
  • Написать первую программу и запустить её
  • Познакомиться с интерфейсом и горячими клавишами

💡 Почему именно VS Code?

Возможно, вы слышали про PyCharm, IDLE или даже Jupyter Notebook как отдельное приложение. Почему мы выбираем VS Code?

  • Это стандарт индустрии. В 2026 году более 70% разработчиков в мире используют VS Code.
  • Всё в одном месте. Код, терминал, отладчик, Git, Jupyter-ноутбуки — не нужно переключаться между окнами.
  • Умные подсказки. Автодополнение, проверка ошибок, AI-помощники (Copilot) — пишут код за вас.
  • Бесплатный и лёгкий. Работает даже на слабых школьных компьютерах.
💡 Интересный факт VS Code написан самой Microsoft, но при этом имеет открытый исходный код. Его используют не только для Python, но и для JavaScript, Rust, Go, C++ и десятков других языков.
1

📥 Установка VS Code

Перейдите на официальный сайт:

https://code.visualstudio.com

Сайт автоматически определит вашу операционную систему. Нажмите большую синюю кнопку Download.

Во время установки (Windows):

  • ✅ Поставьте галочку «Add to PATH» — это важно!
  • ✅ Поставьте галочку «Add "Open with Code" to file context menu»
  • ✅ Поставьте галочку «Add "Open with Code" to directory context menu»
  • Остальное можно оставить по умолчанию
⚠️ Важно для macOS После установки перетащите VS Code в папку «Программы». Иначе macOS будет ругаться на «повреждённое приложение».
2

🐍 Установка Python

VS Code — это редактор, а Python — это язык, на котором мы будем писать. Установим его:

https://www.python.org/downloads/

Нажмите «Download Python 3.12» (или новее).

КРИТИЧЕСКИ ВАЖНО при установке:

🚨 Не пропустите! В самом первом окне установщика обязательно поставьте галочку «Add python.exe to PATH» (внизу окна). Без этого Python не будет работать из терминала.

Затем нажмите «Install Now» и дождитесь окончания.

Проверка установки

Откройте терминал (в Windows — Win + R, введите cmd, нажмите Enter) и напишите:

python --version

Должно появиться что-то вроде Python 3.12.x. Если видите ошибку — значит, не поставили галочку PATH. Переустановите Python.

Нажми, если успешно установил VS Code и Python!

3

🧩 Установка расширений

Расширения — это «суперсилы» для VS Code. Установим три обязательных:

  1. Откройте VS Code
  2. Нажмите Ctrl + Shift + X (или иконка квадратиков слева)
  3. В поиске введите названия и нажмите Install:
  • 🐍 Python (от Microsoft) — поддержка языка Python
  • 📓 Jupyter (от Microsoft) — для работы с ноутбуками
  • ✨ Pylance (от Microsoft) — умные подсказки кода
💡 Бонусное расширение Если хотите AI-помощника — установите GitHub Copilot или Codeium. Для школьников есть бесплатная лицензия через GitHub Education.
4

🚀 Первая программа: Hello, AI!

Традиция в программировании — первая программа всегда выводит приветствие. Сделаем это:

  1. В VS Code нажмите File → Open Folder и создайте новую папку ai-course
  2. В этой папке создайте файл hello.py (правой кнопкой по папке → New File)
  3. Напишите в нём код:
print("Hello, AI! 🤖")
print("Я начинаю свой путь в мире нейросетей")
print(2 + 2 * 2)
  1. Запустите программу: нажмите ▶️ в правом верхнем углу ИЛИ F5 ИЛИ в терминале:
python hello.py

Если видите в терминале:

Hello, AI! 🤖
Я начинаю свой путь в мире нейросетей

🖥 Знакомство с интерфейсом

VS Code состоит из 5 основных зон:

  • Activity Bar — узкая полоска слева с иконками (файлы, поиск, Git, расширения)
  • Side Bar — панель с деревом файлов и инструментами
  • Editor — центральная часть, где вы пишете код
  • Panel — нижняя панель с терминалом и ошибками
  • Status Bar — самая нижняя полоска с информацией о файле
💡 Совет Скрыть/показать терминал: Ctrl + ` (кнопка с буквой Ё). Это самая используемая комбинация!

⌨️ Горячие клавиши, которые нужно знать

Профессионалы не используют мышь. Попробуйте сразу привыкать:

  • Ctrl + S — сохранить файл
  • Ctrl + ` — открыть/закрыть терминал
  • Ctrl + Shift + P — палитра команд (главный инструмент!)
  • Ctrl + P — быстрый поиск файла
  • Ctrl + D — выделить следующее такое же слово
  • Alt + ↑/↓ — переместить строку вверх/вниз
  • Ctrl + / — закомментировать строку
  • F5 — запустить программу

🚨 Частые проблемы и их решения

«python» не является внутренней или внешней командой

При установке Python не поставили галочку «Add to PATH». Решение: переустановите Python, выбрав «Modify» и поставив галочку.

VS Code не видит Python

Нажмите Ctrl + Shift + P, введите «Python: Select Interpreter» и выберите установленную версию.

Код не запускается при нажатии F5

Убедитесь, что установлено расширение Python. Также проверьте, что файл сохранён (перед именем файла нет точки).

Кракозябры вместо русских букв

В правом нижнем углу нажмите на кодировку (обычно UTF-8) и выберите «Save with Encoding» → UTF-8.
