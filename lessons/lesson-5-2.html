🎯 Zero-shot vs Few-shot

Сила примеров
+150 XP

Zero-shot — это когда вы просите модель сделать что-то без примеров. Few-shot — это когда вы даете модели 2-3 примера того, как нужно выполнить задачу, перед тем как дать ей реальный запрос. Few-shot резко повышает точность!

📝 Сравнение Zero-shot и Few-shot

# Zero-shot prompt (Model might guess the format)
zero_shot_prompt = """
Classify the sentiment of this text: 'The battery life is terrible, but the screen is nice.'
"""

# Few-shot prompt (Model knows exactly what to do)
few_shot_prompt = """
Classify the sentiment of the text as Positive, Negative, or Neutral.

Text: 'I absolutely love this new phone!'
Sentiment: Positive

Text: 'The delivery was delayed by three weeks.'
Sentiment: Negative

Text: 'The battery life is terrible, but the screen is nice.'
Sentiment: 
"""

print("Zero-shot prompt is vague about the output format.")
print("Few-shot prompt clearly demonstrates the expected pattern.")
💡 Почему это работает? Модели являются "продолжателями текста". Давая примеры, вы активируете в памяти модели нужный паттерн, и она с большей вероятностью продолжит текст в том же стиле и формате.

🧠 Chain-of-Thought (CoT)

"Давай подумаем шаг за шагом"
+200 XP

Для сложных логических или математических задач модели часто ошибаются, если пытаются дать ответ сразу. Техника Chain-of-Thought заставляет модель рассуждать вслух, разбивая задачу на промежуточные шаги перед выдачей финального ответа.

📝 Магия фразы "Let's think step by step"

# Standard prompt (Often fails on logic puzzles)
standard_prompt = """
Roger has 5 tennis balls. He buys 2 more cans of tennis balls. 
Each can has 3 tennis balls. How many tennis balls does he have now?
Answer: 
"""

# Chain-of-Thought prompt (Dramatically improves accuracy)
cot_prompt = """
Roger has 5 tennis balls. He buys 2 more cans of tennis balls. 
Each can has 3 tennis balls. How many tennis balls does he have now?

Let's think step by step:
1. Roger starts with 5 balls.
2. He buys 2 cans, and each can has 3 balls. So, 2 * 3 = 6 new balls.
3. Total balls = 5 (initial) + 6 (new) = 11.
Answer: 11

---
The cafeteria had 23 apples. If they used 20 to make lunch and bought 6 more, how many apples do they have?

Let's think step by step:
"""

print("CoT forces the model to show its reasoning, reducing hallucination.")
📚 Научный факт Исследование 2022 года показало, что простое добавление фразы "Let's think step by step" (Давай подумаем шаг за шагом) к промпту увеличивает точность решения математических задач большими моделями с 18% до 79%!

🎭 Роли и Разделители

Структурирование промпта
+200 XP

Два мощных приема: 1) Назначение роли ("Действуй как опытный юрист") настраивает тон и словарь модели. 2) Использование разделителей (````, ###, """) помогает модели четко отделить инструкции от входных данных, предотвращая "prompt injection".

📝 Идеальный шаблон промпта

def build_advanced_prompt(user_text):
    """Constructs a robust prompt using best practices"""
    
    prompt = f"""
    # ROLE
    Act as a professional customer support specialist. 
    Your tone should be empathetic, polite, and concise.

    # TASK
    Analyze the customer's message delimited by triple backticks.
    1. Identify the main issue.
    2. Classify the urgency (Low, Medium, High).
    3. Draft a short, helpful response.

    # FORMAT
    Issue: [issue]
    Urgency: [urgency]
    Response: [response]

    # CUSTOMER MESSAGE
    ```
    {user_text}
    ```
    """
    return prompt

# Test the prompt builder
message = "My order #12345 hasn't arrived and it's been 2 weeks! I need a refund NOW."
print(build_advanced_prompt(message))

📊 Оценка и итерация

Как понять, что промпт хороший?
+250 XP

Создание промпта — это итеративный процесс. Нельзя написать его один раз и забыть. Нужно тестировать его на наборе различных примеров (eval set) и проверять: дает ли модель стабильно правильный формат и точный ответ?

📝 Тестирование промпта на датасете

# A mini evaluation dataset
eval_data = [
    {"input": "Great product, fast shipping!", "expected_sentiment": "Positive"},
    {"input": "It's okay, nothing special.", "expected_sentiment": "Neutral"},
    {"input": "Worst experience ever, broken on arrival.", "expected_sentiment": "Negative"}
]

prompt_template = """
Classify sentiment as Positive, Negative, or Neutral.
Text: {text}
Sentiment: 
"""

correct_predictions = 0

for item in eval_data:
    # Simulate LLM call (in reality, you'd use an API here)
    prompt = prompt_template.format(text=item["input"])
    
    # Mock LLM response based on simple keyword matching for this demo
    text_lower = item["input"].lower()
    if "great" in text_lower or "fast" in text_lower:
        mock_response = "Positive"
    elif "worst" in text_lower or "broken" in text_lower:
        mock_response = "Negative"
    else:
        mock_response = "Neutral"
        
    if mock_response == item["expected_sentiment"]:
        correct_predictions += 1

accuracy = (correct_predictions / len(eval_data)) * 100
print(f"Prompt Accuracy on Eval Set: {accuracy:.1f}%")
print("If accuracy is low, we must iterate and improve the prompt!")

БОСС-ФАЙТ: Авто-ответчик для поддержки

Собираем всё вместе в Python-приложение
+500 XP
🤖 Пришло время создать реальное приложение! Мы напишем класс на Python, который принимает жалобы клиентов, использует Few-shot + CoT + Роли для генерации идеального ответа и оценивает его безопасность.

📝 Класс PromptEngineer

class PromptEngineer:
    """A robust prompt engineering pipeline for customer support"""
    
    def __init__(self):
        self.few_shot_examples = """
        Customer: "My screen is cracked."
        Issue: Hardware damage
        Urgency: High
        Response: "I'm so sorry to hear about your screen. Let's get this sorted. Please provide your order number so we can initiate a replacement."
        """
    
    def build_prompt(self, customer_message):
        return f"""
        Act as a senior customer support agent. Be empathetic and professional.
        
        Analyze the message delimited by ``` and provide:
        1. Issue (short summary)
        2. Urgency (Low, Medium, High)
        3. Response (draft a reply)
        
        Let's think step by step.
        
        Examples:
        {self.few_shot_examples}
        
        Customer Message:
        ```
        {customer_message}
        ```
        """
    
    def mock_llm_call(self, prompt):
        """Simulates an LLM API call for educational purposes"""
        # In a real app, this would be: openai.ChatCompletion.create(...)
        if "refund" in prompt.lower() or "angry" in prompt.lower():
            return "Issue: Billing dispute\nUrgency: High\nResponse: I understand your frustration regarding the refund. I have escalated this to our billing team. You will receive an update within 24 hours."
        else:
            return "Issue: General inquiry\nUrgency: Medium\nResponse: Thank you for reaching out! I'd be happy to help you with that. Could you please provide a bit more detail?"

# Run the Boss Fight
engineer = PromptEngineer()

messages = [
    "I am very angry! I want a refund immediately!",
    "Hi, what are your working hours?"
]

for msg in messages:
    print(f"\n--- Customer: '{msg}' ---")
    prompt = engineer.build_prompt(msg)
    print("Generated Prompt:\n", prompt[:150] + "... [truncated]")
    
    response = engineer.mock_llm_call(prompt)
    print("\nAI Response:\n", response)
