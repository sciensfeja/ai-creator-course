Зачем нужны функции активации?

Почему линейности недостаточно
+50 XP

Если убрать все функции активации из нейросети, она превратится в обычную линейную регрессию — сколько бы слоёв ты ни добавлял. Функции активации вводят нелинейность, позволяя сети аппроксимировать сложные зависимости.

🎮
Игровая аналогия Представь, что ты складываешь урон от разных зелий. Если все зелья просто складываются (линейность), ты не получишь комбо-эффекта. Функция активации — это как «критический удар»: она добавляет нелинейный буст, который делает комбинацию зелий мощнее простой суммы!

📈 Sigmoid и Tanh

Классические функции активации
+100 XP

Sigmoid сжимает любое число в диапазон (0, 1) — идеально для вероятностей. Tanh (гиперболический тангенс) сжимает в диапазон (-1, 1) — центрирован вокруг нуля, что помогает градиентам.

📝 Реализация Sigmoid и Tanh

import numpy as np
import matplotlib.pyplot as plt

# Sigmoid function: maps any value to (0, 1)
def sigmoid(z):
    return 1 / (1 + np.exp(-z))

# Tanh function: maps any value to (-1, 1)
def tanh(z):
    return np.tanh(z)

# Generate input values
z = np.linspace(-6, 6, 100)

# Plot both functions
plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
plt.plot(z, sigmoid(z), label='Sigmoid', color='#00c8ff', linewidth=2)
plt.axhline(y=0.5, color='gray', linestyle='--', alpha=0.5)
plt.title('Sigmoid: Output in (0, 1)')
plt.xlabel('Input (z)')
plt.ylabel('Output')
plt.legend()
plt.grid(True, alpha=0.3)

plt.subplot(1, 2, 2)
plt.plot(z, tanh(z), label='Tanh', color='#ff50a0', linewidth=2)
plt.axhline(y=0, color='gray', linestyle='--', alpha=0.5)
plt.title('Tanh: Output in (-1, 1)')
plt.xlabel('Input (z)')
plt.ylabel('Output')
plt.legend()
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

# Test values
print(f"Sigmoid(0) = {sigmoid(0):.3f}")    # 0.5
print(f"Sigmoid(2) = {sigmoid(2):.3f}")    # 0.881
print(f"Tanh(0) = {tanh(0):.3f}")          # 0.0
print(f"Tanh(2) = {tanh(2):.3f}")          # 0.964
⚠️ Проблема затухающих градиентов Sigmoid и Tanh страдают от «vanishing gradients»: при больших или маленьких значениях z градиент почти равен нулю, и нейрон перестаёт учиться. Это главная причина, почему в глубоких сетях используют ReLU.

⚡ ReLU и её вариации

Самая популярная функция в современных сетях
+120 XP

ReLU (Rectified Linear Unit) — самая используемая функция активации в глубоких сетях. Она проста: f(x) = max(0, x). Но у неё есть проблема «мёртвых нейронов» — если нейрон всегда выдаёт отрицательное значение, он «умирает». Решения: Leaky ReLU и ELU.

📝 Семейство ReLU

import numpy as np
import matplotlib.pyplot as plt

# ReLU: max(0, x)
def relu(z):
    return np.maximum(0, z)

# Leaky ReLU: allows small negative slope
def leaky_relu(z, alpha=0.01):
    return np.where(z > 0, z, alpha * z)

# ELU: Exponential Linear Unit
def elu(z, alpha=1.0):
    return np.where(z > 0, z, alpha * (np.exp(z) - 1))

# Generate input values
z = np.linspace(-3, 3, 100)

# Plot all ReLU variants
plt.figure(figsize=(12, 5))

plt.subplot(1, 2, 1)
plt.plot(z, relu(z), label='ReLU', color='#00c8ff', linewidth=2)
plt.plot(z, leaky_relu(z), label='Leaky ReLU', color='#ff50a0', linewidth=2, linestyle='--')
plt.plot(z, elu(z), label='ELU', color='#ffb400', linewidth=2, linestyle=':')
plt.axhline(y=0, color='gray', linestyle='--', alpha=0.5)
plt.title('ReLU Family')
plt.xlabel('Input (z)')
plt.ylabel('Output')
plt.legend()
plt.grid(True, alpha=0.3)

# Zoom in on negative region
plt.subplot(1, 2, 2)
z_neg = np.linspace(-1, 0, 100)
plt.plot(z_neg, relu(z_neg), label='ReLU', color='#00c8ff', linewidth=2)
plt.plot(z_neg, leaky_relu(z_neg), label='Leaky ReLU', color='#ff50a0', linewidth=2, linestyle='--')
plt.plot(z_neg, elu(z_neg), label='ELU', color='#ffb400', linewidth=2, linestyle=':')
plt.title('Negative Region (Zoomed)')
plt.xlabel('Input (z)')
plt.ylabel('Output')
plt.legend()
plt.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()

print("ReLU variants visualized! Notice how Leaky ReLU and ELU handle negative values.")
📚 Лор для гиков ReLU стала революцией в 2012 году благодаря AlexNet. До неё все использовали Sigmoid и Tanh, но они слишком медленно обучались в глубоких сетях. ReLU решила проблему затухающих градиентов для положительных значений, ускорив обучение в 10 раз!

🎯 Softmax: Многоклассовая классификация

Когда нужно выбрать один класс из многих
+150 XP

Softmax превращает вектор чисел в распределение вероятностей: все значения от 0 до 1, и их сумма равна 1. Используется в последнем слое сети для многоклассовой классификации (например, распознавание цифр 0-9).

📝 Реализация Softmax

import numpy as np

def softmax(z):
    # Subtract max for numerical stability
    exp_z = np.exp(z - np.max(z))
    return exp_z / exp_z.sum(axis=0)

# Example: neural network outputs for 3 classes (cat, dog, bird)
raw_outputs = np.array([2.0, 1.0, 0.1])

# Apply softmax to get probabilities
probabilities = softmax(raw_outputs)

print(f"Raw outputs: {raw_outputs}")
print(f"Probabilities: {probabilities}")
print(f"Sum of probabilities: {probabilities.sum():.3f}")  # Should be 1.0
print(f"\nPredicted class: {np.argmax(probabilities)} (Cat)")

# Test with different inputs
print("\n--- More examples ---")
test_cases = [
    np.array([1.0, 1.0, 1.0]),      # Equal probabilities
    np.array([10.0, 1.0, 0.1]),     # One dominant class
    np.array([-1.0, -2.0, -3.0])    # All negative
]

for i, case in enumerate(test_cases):
    probs = softmax(case)
    print(f"Case {i+1}: {case} -> {probs.round(3)}")
💡 Зачем вычитать максимум? Строка z - np.max(z) нужна для численной стабильности. Без неё exp() может переполниться при больших значениях z, вызвав ошибку overflow. Вычитание максимума не меняет результат, но предотвращает переполнение.

🔬 Сравнение функций активации

Когда какую использовать?
+150 XP

Каждая функция активации имеет свои сильные и слабые стороны. Давай сравним их на одной задаче и посмотрим, как быстро каждая из них сходится.

📝 Сравнение на задаче XOR

import numpy as np

# XOR problem data
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
y = np.array([[0], [1], [1], [0]])

# Activation functions
def sigmoid(z):
    return 1 / (1 + np.exp(-np.clip(z, -500, 500)))

def relu(z):
    return np.maximum(0, z)

def tanh(z):
    return np.tanh(z)

# Simple neural network with different activations
def train_network(activation_func, learning_rate=0.1, epochs=1000):
    np.random.seed(42)
    weights1 = np.random.randn(2, 4) * 0.5
    bias1 = np.zeros((1, 4))
    weights2 = np.random.randn(4, 1) * 0.5
    bias2 = np.zeros((1, 1))
    
    for epoch in range(epochs):
        # Forward pass
        hidden = activation_func(np.dot(X, weights1) + bias1)
        output = sigmoid(np.dot(hidden, weights2) + bias2)
        
        # Backward pass (simplified)
        error = y - output
        # ... (gradient calculation omitted for brevity)
    
    return output

# Train with different activations
print("Training XOR with different activations...\n")

activations = [
    ('Sigmoid', sigmoid),
    ('Tanh', tanh),
    ('ReLU', relu)
]

for name, func in activations:
    result = train_network(func)
    print(f"{name}:")
    for i, (inp, out) in enumerate(zip(X, result)):
        print(f"  Input {inp} -> {out[0]:.3f} (target: {y[i][0]})")
    print()
🏆 В современных глубоких сетях ReLU доминирует в скрытых слоях, Sigmoid используется в бинарной классификации, а Softmax — в многоклассовой. Tanh встречается реже, но полезен в RNN!
