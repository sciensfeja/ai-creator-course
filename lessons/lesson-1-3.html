Почему Python-списков мало?

Знакомство с библиотекой NumPy
+40 XP

Обычные списки в Python хороши для хранения данных, но они медленные для математики. Представь, что тебе нужно умножить 1000 чисел на 2. В обычном списке придётся писать цикл. В NumPy это делается в одну строку и работает в 100 раз быстрее!

Игровая аналогия Обычный список — это как идти пешком. NumPy — это как телепорт. Нейросети обрабатывают миллионы чисел, и без NumPy обучение ChatGPT заняло бы не месяцы, а тысячи лет!

📝 Твой первый массив NumPy

import numpy as np

# Creating a simple Python list
python_list = [1, 2, 3, 4, 5]

# Converting it to a NumPy array
numpy_array = np.array(python_list)

print("Python list:", python_list)
print("NumPy array:", numpy_array)

# Math magic: multiply all elements by 2 at once!
print("Multiplied by 2:", numpy_array * 2)
💡 Правило импорта В мире Python библиотеку NumPy всегда импортируют как np. Это как универсальный никнейм. Если увидишь в чужом коде np.array() — знай, это NumPy.

📐 Векторы: Стрелки в пространстве

Связь с геометрией
+60 XP

В геометрии вектор — это стрелка, у которой есть направление и длина. В программировании вектор — это просто одномерный массив (список чисел). Координаты точки (x, y) — это вектор!

📝 Считаем длину вектора

# A 1D array represents a vector in geometry
# Vector coordinates: x=3, y=4
vector = np.array([3, 4])

# Calculate the magnitude (length) of the vector
# Using the Pythagorean theorem: sqrt(3^2 + 4^2) = 5
magnitude = np.linalg.norm(vector)

print(f"Vector: {vector}")
print(f"Magnitude (length): {magnitude}")
Лор для гиков В нейросетях каждое слово превращается в вектор из сотен чисел (эмбеддинг). Смысл слов определяется «расстоянием» между их векторами. Векторы слов «король» и «королева» будут очень близко друг к другу!

🔲 Матрицы: Как ИИ видит картинки

Двумерные массивы
+80 XP

Матрица — это таблица чисел (строки и столбцы). В NumPy это двумерный массив. Самое важное: любая цифровая картинка — это матрица! Чёрно-белое фото — это матрица, где каждое число это яркость пикселя (от 0 до 255).

📝 Создаём матрицу 3x3

# A 2D array represents a matrix
# Think of it as a tiny 3x3 pixel image
matrix = np.array([
    [1, 0, 1],
    [0, 1, 0],
    [1, 0, 1]
])

print("Matrix shape (rows, cols):", matrix.shape)
print("Our matrix:")
print(matrix)
👁️ Для тебя это крестик из единиц и нулей. Для нейросети — это полноценное изображение, которое она может классифицировать!

💥 Скалярное произведение: Сердце ИИ

Самая важная операция в нейросетях
+100 XP

Если ты запомнишь только одну вещь из этого урока — запомни скалярное произведение (dot product). Это операция, при которой мы перемножаем соответствующие элементы двух векторов и складываем результаты. Именно так нейрон «принимает решение»!

📝 Считаем Dot Product

# The dot product is the core operation in neural networks
vector_a = np.array([1, 2, 3])
vector_b = np.array([4, 5, 6])

# Dot product: (1*4) + (2*5) + (3*6) = 4 + 10 + 18 = 32
dot_product = np.dot(vector_a, vector_b)

print(f"Vector A: {vector_a}")
print(f"Vector B: {vector_b}")
print(f"Dot Product: {dot_product}")
💡 Как это работает в нейросети? Вектор A — это входные данные (например, пиксели картинки). Вектор B — это «веса» нейрона (его память). Скалярное произведение показывает, насколько входные данные похожи на то, что нейрон «запомнил». Чем больше число — тем сильнее сигнал!

БОСС-ФАЙТ: Обработка изображений

Применяем математику к картинке
+200 XP
🖼️✨ Ты уже знаешь, что картинка — это матрица. Давай применим к ней математическую магию, как это делают фоторедакторы и нейросети!

Делаем картинку темнее

# Imagine a tiny 4x4 grayscale image
# 0 is black, 255 is white
image_matrix = np.array([
    [0, 0, 0, 0],
    [0, 255, 255, 0],
    [0, 255, 255, 0],
    [0, 0, 0, 0]
])

# Apply a simple filter: make it darker by dividing by 2
darker_image = image_matrix / 2

print("Original image matrix:")
print(image_matrix)
print("\nDarker image matrix:")
print(darker_image)
🚨 Проверь перед сдачей босса Код запустился? Матрица стала в два раза меньше (максимум 127.5 вместо 255)? Поздравляю — ты только что написал алгоритм обработки изображений! 🏆
