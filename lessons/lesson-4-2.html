✂️ Что такое токенизация?

Разбиение текста на части
+150 XP

Токенизация — это процесс разбиения текста на меньшие части, называемые токенами. Токен может быть словом, частью слова или даже символом. Например, "ChatGPT" может быть разбит на ["Chat", "G", "PT"] или ["Chat", "GPT"] в зависимости от метода.

Токенизация с HuggingFace

from transformers import AutoTokenizer

# Load pre-trained tokenizer (GPT-2)
tokenizer = AutoTokenizer.from_pretrained('gpt2')

# Tokenize text
text = "Hello, world! ChatGPT is amazing."
tokens = tokenizer.tokenize(text)

print(f"Original text: {text}")
print(f"Tokens: {tokens}")

# Convert tokens to IDs (numbers)
token_ids = tokenizer.convert_tokens_to_ids(tokens)
print(f"Token IDs: {token_ids}")

# Full tokenization (returns dictionary)
encoded = tokenizer(text, return_tensors='pt')
print(f"\nEncoded output:")
print(f"Input IDs: {encoded['input_ids']}")
print(f"Attention mask: {encoded['attention_mask']}")

# Decode back to text
decoded = tokenizer.decode(encoded['input_ids'][0])
print(f"\nDecoded: {decoded}")
💡 Что такое attention mask? Attention mask показывает, какие токены являются реальными (1), а какие — padding (0). Padding добавляется, чтобы все последовательности в батче имели одинаковую длину.

Типы токенизации

Word, Subword, Character
+200 XP

Существует три основных типа токенизации: Word-level (по словам), Subword-level (по частям слов), и Character-level (по символам). Каждый имеет свои плюсы и минусы. Современные модели (GPT, BERT) используют subword токенизацию.

📝 Сравнение типов токенизации

# Word-level tokenization (simple split)
text = "The quick brown fox jumps"
word_tokens = text.split()
print(f"Word tokens: {word_tokens}")
print(f"Vocabulary size: ~100,000 words")

# Subword tokenization (BPE - Byte Pair Encoding)
from transformers import AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained('bert-base-uncased')
text = "unbelievable"
subword_tokens = tokenizer.tokenize(text)
print(f"\nSubword tokens: {subword_tokens}")
print(f"Vocabulary size: ~30,000 tokens")

# Character-level tokenization
char_tokens = list(text)
print(f"\nCharacter tokens: {char_tokens}")
print(f"Vocabulary size: ~100 characters")

# Show tokenization of rare word
rare_word = "supercalifragilisticexpialidocious"
print(f"\nRare word: {rare_word}")
print(f"Word tokens: ['{rare_word}'] (OOV problem!)")
print(f"Subword tokens: {tokenizer.tokenize(rare_word)}")
print(f"Character tokens: {list(rare_word)}")
📚 Проблема OOV OOV (Out-of-Vocabulary) — когда слово не встречается в словаре токенизатора. Word-level токенизация не знает, что делать с редкими словами. Subword токенизация решает эту проблему, разбивая редкие слова на известные части!

🔢 Что такое эмбеддинги?

Векторное представление слов
+250 XP

Эмбеддинг — это вектор (список чисел), который представляет токен в многомерном пространстве. Слова с похожим значением имеют близкие векторы. Например, векторы "кот" и "кошка" будут ближе друг к другу, чем к вектору "автомобиль".

🗺️
Игровая аналогия Представь карту мира, где города — это слова. Близкие по смыслу слова (Москва и Санкт-Петербург) находятся рядом. Далёкие по смыслу (Москва и ананас) — далеко друг от друга. Эмбеддинги — это координаты слов на этой карте!

📝 Визуализация эмбеддингов

import numpy as np
import matplotlib.pyplot as plt
from sklearn.decomposition import PCA

# Simulated word embeddings (300-dimensional like Word2Vec)

    'king': np.random.randn(300),
    'queen': np.random.randn(300),
    'man': np.random.randn(300),
    'woman': np.random.randn(300),
    'prince': np.random.randn(300),
    'princess': np.random.randn(300),
    'car': np.random.randn(300),
    'bicycle': np.random.randn(300),
    'airplane': np.random.randn(300),
    'cat': np.random.randn(300),
    'dog': np.random.randn(300),
    'apple': np.random.randn(300)
}

# Make similar words actually similar (for demo)
word_embeddings['queen'] = word_embeddings['king'] + np.random.randn(300) * 0.1
word_embeddings['woman'] = word_embeddings['man'] + np.random.randn(300) * 0.1
word_embeddings['princess'] = word_embeddings['prince'] + np.random.randn(300) * 0.1
word_embeddings['dog'] = word_embeddings['cat'] + np.random.randn(300) * 0.1
word_embeddings['bicycle'] = word_embeddings['car'] + np.random.randn(300) * 0.1

# Reduce dimensionality to 2D for visualization
words = list(word_embeddings.keys())
embeddings_matrix = np.array([word_embeddings[w] for w in words])

pca = PCA(n_components=2)

# Plot

plt.scatter(embeddings_2d[:, 0], embeddings_2d[:, 1], s=200, alpha=0.6)

for i, word in enumerate(words):
    plt.annotate(word, (embeddings_2d[i, 0], embeddings_2d[i, 1]), 
                fontsize=12, fontweight='bold')

plt.title('Word Embeddings Visualization (PCA)', fontsize=14, fontweight='bold')
plt.xlabel('Principal Component 1')
plt.ylabel('Principal Component 2')
plt.grid(True, alpha=0.3)
plt.tight_layout()
plt.show()

print("Embeddings visualized! Similar words should cluster together.")

🤖 Современные эмбеддинги

BERT, GPT и контекстуальные эмбеддинги
+300 XP

Классические эмбеддинги (Word2Vec, GloVe) дают каждому слову один фиксированный вектор. Но слово "bank" может означать "банк" (финансовый) или "берег" (реки)! Современные модели (BERT, GPT) создают контекстуальные эмбеддинги — вектор зависит от контекста.

📝 Контекстуальные эмбеддинги с BERT

import torch
from transformers import AutoTokenizer, AutoModel

# Load BERT model and tokenizer
tokenizer = AutoTokenizer.from_pretrained('bert-base-uncased')
model = AutoModel.from_pretrained('bert-base-uncased')

# Two sentences with the word "bank" in different contexts
sentences = [
    "I deposited money in the bank.",
    "We sat on the river bank."
]

# Tokenize and get embeddings
for sentence in sentences:
    inputs = tokenizer(sentence, return_tensors='pt')
    
    with torch.no_grad():
        outputs = model(**inputs)
    
    # Get embeddings for all tokens
    embeddings = outputs.last_hidden_state
    
    # Find "bank" token
    tokens = tokenizer.tokenize(sentence)
    bank_idx = tokens.index('bank')
    
    bank_embedding = embeddings[0, bank_idx + 1]  # +1 for [CLS] token
    
    print(f"Sentence: {sentence}")
    print(f"Tokens: {tokens}")
    print(f"Bank embedding shape: {bank_embedding.shape}")
    print(f"Bank embedding (first 5 dims): {bank_embedding[:5]}")
    print()

# Compare embeddings
inputs1 = tokenizer(sentences[0], return_tensors='pt')
inputs2 = tokenizer(sentences[1], return_tensors='pt')

with torch.no_grad():
    emb1 = model(**inputs1).last_hidden_state
    emb2 = model(**inputs2).last_hidden_state

# Cosine similarity between "bank" in two contexts
bank1 = emb1[0, 5]  # "bank" in first sentence
bank2 = emb2[0, 6]  # "bank" in second sentence

similarity = torch.nn.functional.cosine_similarity(bank1, bank2, dim=0)
print(f"Cosine similarity between 'bank' in two contexts: {similarity.item():.4f}")
print("(Lower similarity = different meanings!)")
⚠️ Почему это важно? Контекстуальные эмбеддинги — это прорыв! BERT понимает, что "bank" в разных предложениях имеет разные значения. Именно это позволяет GPT и другим моделям генерировать осмысленный текст!

📝 Семантический поиск с эмбеддингами

import torch
import numpy as np
from transformers import AutoTokenizer, AutoModel
from sklearn.metrics.pairwise import cosine_similarity

# Load model
tokenizer = AutoTokenizer.from_pretrained('bert-base-uncased')
model = AutoModel.from_pretrained('bert-base-uncased')

# Database of texts (e.g., product descriptions, articles)
database = [
    "The quick brown fox jumps over the lazy dog",
    "A fast animal leaps across a sleeping pet",
    "Machine learning is a subset of artificial intelligence",
    "Deep learning uses neural networks with many layers",
    "The stock market crashed today",
    "Financial markets experienced significant losses",
    "How to bake a chocolate cake",
    "Recipe for making delicious brownies"
]

# Function to get text embeddings
def get_embedding(text):
    inputs = tokenizer(text, return_tensors='pt', truncation=True, max_length=512)
    with torch.no_grad():
        outputs = model(**inputs)
    # Use mean pooling
    return outputs.last_hidden_state.mean(dim=1).squeeze().numpy()

# Get embeddings for all database texts
print("Computing embeddings for database...")
db_embeddings = [get_embedding(text) for text in database]

# Search query
query = "AI and neural networks"
query_embedding = get_embedding(query)

# Calculate similarity
similarities = cosine_similarity([query_embedding], db_embeddings)[0]

# Get top 3 most similar texts
top_indices = np.argsort(similarities)[::-1][:3]

print(f"\nQuery: {query}")
print(f"\nTop 3 most similar texts:")
for rank, idx in enumerate(top_indices, 1):
    print(f"{rank}. (Similarity: {similarities[idx]:.4f})")
    print(f"   {database[idx]}")
    print()

# Interactive search
print("\n--- Interactive Search ---")
while True:
    user_query = input("\nEnter search query (or 'quit' to exit): ")
    if user_query.lower() == 'quit':
        break
    
    query_emb = get_embedding(user_query)
    sims = cosine_similarity([query_emb], db_embeddings)[0]
    top_idx = np.argsort(sims)[::-1][:3]
    
    print(f"\nTop results for '{user_query}':")
    for rank, idx in enumerate(top_idx, 1):
        print(f"{rank}. (Score: {sims[idx]:.4f}) {database[idx]}")
