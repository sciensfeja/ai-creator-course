🎒 Инвентарь: Переменные

Учимся хранить данные
+40 XP

В любой RPG у героя есть инвентарь — рюкзак, где лежат мечи, зелья, золото. В Python роль инвентаря играют переменные. Это такие «коробочки с подписями», куда можно положить что угодно.

⚔️
Сравни с игрой В Minecraft ты кладёшь алмазы в ячейку с подписью diamonds. В Python — то же самое, только вместо алмазов — числа, текст, True/False. А вместо ячеек — переменные.

📝 Создаём свой инвентарь

# My character in the "AI Creator" game
hero_name = "Alya"          # Hero name
hero_level = 10             # Level
hero_hp = 100.0             # Health points (can be fractional)
has_magic_sword = True      # Does the hero have a magic sword?

print("Hero:", hero_name)
print("Level:", hero_level)
print("HP:", hero_hp)
print("Magic sword:", has_magic_sword)
💡 Правило naming-а (как в Genshin) Называй переменные понятно. x = 5 — плохо (кто такой x?). hero_hp = 100 — хорошо (сразу ясно, что это HP героя). Как с никами в играх: player1 скучно, а DragonSlayer2009 — уже интереснее 😄

🧪 Классы предметов: Типы данных

Что может лежать в инвентаре
+40 XP

В играх предметы делятся на классы: оружие, броня, зелья, квестовые вещи. Нельзя надеть зелье как шлем. В Python точно так же: у каждого значения есть тип. И нельзя, например, сложить число с текстом.

4 главных типа данных (как 4 стихии в играх)

  • 🔥 int (целое число) — 10, -5, 2026. Как количество золота.
  • 💧 float (дробное число) — 3.14, 99.5. Как HP, может быть нецелым.
  • 🌪 str (строка, текст) — "Привет", "Gandalf". Как имя NPC.
  • ⚡ bool (True/False) — только два значения. Как переключатель: жив/мёртв, есть квест/нет квеста.
🧙
AI-контекст Нейросети видят мир именно в этих типах! int — количество пикселей, float — вес синапса, str — текст сообщения, bool — спам/не спам. Так что типы данных — это алфавит, на котором говорит ИИ.

🔍 Проверяем тип предмета

gold = 1000
hp = 99.5
name = "Gandalf"
is_alive = True

print(type(gold))      # <class 'int'>
print(type(hp))        # <class 'float'>
print(type(name))      # <class 'str'>
print(type(is_alive))  # <class 'bool'>
💀 «Я пытался сложить "5" + 5 и получил ошибку. Оказалось, Python не настолько умный, чтобы догадаться, что "5" — это тоже число»

💬 Диалог с NPC: input() и print()

Учим бота общаться
+50 XP

В играх есть диалоговые окна: NPC задаёт вопрос, ты выбираешь ответ. В Python эту магию делают две функции:

  • print() — NPC говорит тебе (вывод на экран)
  • input() — NPC слушает тебя (ввод с клавиатуры)

📝 Первая диалоговая сцена

print("🤖 Hello, traveler! What's your name?")
name = input()  # Wait for the player to enter their name

print("🤖 Nice to meet you, " + name + "!")
print(" How old are you?")
age = input()

# Beautiful output using f-string (Python magic!)
print(f"🤖 Cool, {name}! Saving the world at {age}? Respect! 🔥")
⚠️ Ловушка для новичков! input() всегда возвращает строку, даже если ты ввёл число. Хочешь использовать возраст в математике? Превращай в число: age = int(input()). Это как в играх: чтобы купить предмет, золото должно быть числом, а не текстом «сто».

🌳 Ветвление сюжета: if / elif / else

Первый классификатор ИИ
+60 XP

Помнишь игры с выбором реплик? (Detroit: Become Human, Mass Effect, Witcher). Ты выбираешь ответ — и сюжет идёт по-разному. В Python за это отвечают условия if / elif / else.

🎭
Это и есть ИИ! Любой ИИ-классификатор — это на самом деле очень много if-ов. Определяет, кот на фото или собака? if пикселей в ушах много → кот. Спам в почте? if слово «казино» → спам. Позже мы заменим if-ы на нейросети, но суть останется та же.

📝 ИИ-классификатор настроения

print("🤖 How are you doing? Be honest:")
mood = input().lower()  # .lower() converts text to lowercase

if "great" in mood or "super" in mood or "good" in mood:
    print(" 😄 Cool! Keep this energy up all day!")
elif "okay" in mood or "alright" in mood or "so-so" in mood:
    print("🤖 😌 Okay is good enough. But you can do better!")
elif "bad" in mood or "sad" in mood or "tired" in mood:
    print("🤖  Hang in there! It will pass. Want to hear a joke?")
else:
    print("🤖 🤔 Hmm, I didn't understand. Can you say it simpler?")
📚 Лор для гиков То, что ты только что написал — это rule-based chatbot (чат-бот на правилах). Именно так работали первые «говорящие» программы в 1960-х! Самый известный — ELIZA, которая притворялась психотерапевтом. Твой бот — её правнук 😎

🔄 Гриндилка: Циклы for и while

Обрабатываем датасеты
+60 XP

В играх есть гринд — когда ты убиваешь 100 одинаковых мобов ради лута. Скучно? Зато эффективно. Циклы в Python — это легальный гринд: одна и та же операция много раз, но без скуки.

🔁 for — когда знаем, сколько раз гриндить

# Processing a "dataset" of player names
players = ["Alya", "Bolat", "Dima", "Eva"]

for player in players:
    print(f"👋 Hi, {player}! Welcome to AI Creator!")

# Classic grinding: 10 times
for i in range(10):
    print(f"️ Killed mob #{i+1}. Loot +100 XP")

🔁 while — когда гриндим, пока не достигнем цели

# The bot learns to guess the number
import random
secret = random.randint(1, 10)  # Secret number from 1 to 10
attempts = 0

print(" I picked a number from 1 to 10. Guess it!")

while True:
    guess = int(input("Your guess: "))
    attempts += 1
    
    if guess == secret:
        print(f"🤖 🎉 Guessed it in {attempts} attempts! You're a genius!")
        break  # Exit the loop
    elif guess < secret:
        print("🤖 📈 Higher!")
    else:
        print(" 📉 Lower!")
🎮
Связь с нейросетями Обучение нейросети — это огромный цикл while: «пока ошибка большая → делаем шаг обучения → проверяем снова». Именно поэтому обучение ChatGPT заняло месяцы на тысячах видеокарт. Это был очень дорогой гринд 💸

📦 Сундуки и книги: Списки и словари

Память бота
+60 XP

Чтобы бот был умным, ему нужна память. В Python для этого есть две структуры:

📜 Списки — как инвентарь (упорядоченный)

# Hero's inventory
inventory = ["sword", "potion", "shield", "500 gold"]

print(inventory[0])      # sword (indexing starts at 0!)
inventory.append("bow")  # Added a new item
print(inventory)         # ['sword', 'potion', 'shield', '500 gold', 'bow']

📖 Словари — как база знаний (ключ → значение)

# Bot's knowledge base
bot_knowledge = {
    "hello": "Hello, hero! 👋",
    "how are you": "I'm doing great, thanks! ",
    "bye": "See you later, traveler! 🚀"
}

# Looking for an answer in the knowledge base
question = input("Ask me something: ").lower()
if question in bot_knowledge:
    print("🤖", bot_knowledge[question])
else:
    print("🤖 🤷 I don't know that one. Teach me!")
🧠✨ Поздравляю! Ты только что написал свою первую «базу знаний». ChatGPT использует ту же идею, только словарь у него на 2 триллиона параметров. Но суть та же!

⚡ Скиллы героя: Функции

Превращаем код в переиспользуемые скиллы
+70 XP

В играх у героя есть набор скиллов: удар мечом, огненный шар, хил. Каждый скилл — это отдельная способность, которую можно использовать много раз. В Python скиллы называются функциями.

🔥
Функция = нейрон Функция получает входы (аргументы), делает что-то внутри и возвращает выход (результат). Это в точности как искусственный нейрон! Позже в курсе мы соберём из таких «нейронов» целую нейросеть.

📝 Пишем скиллы для бота

def greet(name):

    """Skill #2: Ask about mood"""

💡 Прокачка скиллов Функции — это DRY-принцип (Don't Repeat Yourself). Один раз написал — используешь везде. Как в играх: выучил огненный шар → кидаешь его во всех боссов. Не надо каждый раз заново учить.

Финальный проект урока

📝 Финальный код бота

# ==========================================
# 🤖 MY FIRST AI BOT
# Author: [your name]
# ==========================================

def greet(name):
    print(f"🤖 Hi, {name}! I am your AI bot.")
    print("🤖 Let's chat!")

def ask_mood():
    print("\n How are you doing today?")
    return input("→ ").lower()

def classify_mood(text):
    if any(word in text for word in ["great", "super", "awesome", "cool"]):
        return "happy"
    elif any(word in text for word in ["okay", "ok", "fine", "alright"]):
        return "neutral"
    elif any(word in text for word in ["bad", "sad", "tired", "terrible"]):
        return "sad"
    else:
        return "unknown"

def respond(mood):
    print()
    if mood == "happy":
        print("🤖 😄 Awesome! Happy for you! This energy is your superpower.")
    elif mood == "neutral":
        print(" 😌 Stability is a sign of mastery.")
    elif mood == "sad":
        print(" 🫂 Hey, I'm here. Want to hear a programmer joke?")
        print("   — Why do programmers prefer dark mode? Because light attracts bugs! 😄")
    else:
        print("🤖 🤔 Hmm, interesting. Tell me more?")

def main():
    print("=" * 40)
    print(" LAUNCHING AI BOT v1.0")
    print("=" * 40)
    
    name = input("🤖 What's your name? → ")
    greet(name)
    
    mood_text = ask_mood()
    mood = classify_mood(mood_text)
    respond(mood)
    
    print(f"\n🤖 Thanks for chatting, {name}! Come back soon! 🚀")

# Let's launch the bot!
if __name__ == "__main__":
    main()
