🎨 Чертёж vs Герой: Что такое класс?

Главная идея ООП за 30 секунд
+30 XP

Представь: ты играешь в Genshin Impact. Там сотни персонажей — Архонты, путешественники, боссы. Но разработчикам не пришлось писать код для каждого отдельно. Они создали один чертёж — «Персонаж», а потом по нему сделали 100+ героев.

🏗️
ООП = Конструктор LEGO В ООП есть две вещи: Класс (чертёж/инструкция) и Объект (конкретная вещь по этому чертежу). Класс «Персонаж» говорит: «У каждого героя есть имя, HP и атака». А объекты — это конкретные Архонты, которых ты коллекционируешь.
🤯 «Я думал, в играх каждый персонаж — это отдельный код. Оказывается, они все сделаны по одному чертежу, просто с разными параметрами!» — любой, кто впервые понял ООП

📝 Первый класс в Python

class Hero:
    """Это чертёж героя. Пока что пустой."""
    pass

# Создаём объект по чертежу (это называется "инстанцирование")
hero1 = Hero()
hero2 = Hero()

print(hero1)  # <__main__.Hero object at 0x...>
print(hero2)  # <__main__.Hero object at 0x...>
# Это два РАЗНЫХ героя, но пока они абсолютно одинаковые
💡 Запомни правило Классы в Python пишутся с большой буквы (Hero, Monster, Item). Переменные и функции — с маленькой (hero1, attack()). Это как в играх: имена боссов пишут с заглавной, а обычные слова — со строчной.

📊 Статы героя: Атрибуты

Добавляем характеристики персонажу
+50 XP

В любой RPG у героя есть статы: HP, мана, сила, ловкость, интеллект. В Python эти статы называются атрибутами — это переменные, которые «принадлежат» объекту.

📊
Смотри в игру Когда ты открываешь меню персонажа в RPG, ты видишь: Имя, Уровень, HP, Атака. Это и есть атрибуты! А когда нажимаешь «Удар мечом» — это уже метод (о нём на уровне 4).

📝 Добавляем статы герою

class Hero:
    def __init__(self, name, hp, attack):
        # Это КОНСТРУКТОР — он вызывается при создании героя
        self.name = name        # Имя героя
        self.hp = hp            # Здоровье
        self.attack = attack    # Сила атаки
        self.level = 1          # Уровень (у всех начинается с 1)
    
    def show_stats(self):
        # Метод для вывода статов
        print(f"🦸 {self.name} | Ур.{self.level} | HP: {self.hp} | ATK: {self.attack}")

# Создаём героев с разными статами
warrior = Hero("Конан", 150, 25)
mage = Hero("Гэндальф", 80, 40)
archer = Hero("Леголас", 100, 30)

warrior.show_stats()  # 🦸 Конан | Ур.1 | HP: 150 | ATK: 25
mage.show_stats()     # 🦸 Гэндальф | Ур.1 | HP: 80 | ATK: 40
archer.show_stats()   # 🦸 Леголас | Ур.1 | HP: 100 | ATK: 30
⚠️ Магическое слово: self self — это «я», «этот объект». Когда ты пишешь self.name = name, ты говоришь: «У ЭТОГО героя имя равно тому, что передали в конструктор». Без self Python не поймёт, к какому герою относятся статы.

⚔️ Скиллы героя: Методы

Учим персонажа действовать
+60 XP

Мало создать героя со статами — он должен ещё что-то делать! Атаковать, лечиться, получать опыт. В Python действия героя называются методами — это функции, которые «живут» внутри класса.

📝 Добавляем скиллы

class Hero:
    def __init__(self, name, hp, attack):
        self.name = name
        self.hp = hp
        self.max_hp = hp  # Запоминаем максимум HP
        self.attack = attack
        self.level = 1
        self.xp = 0
    
    def show_stats(self):
        print(f"🦸 {self.name} | Ур.{self.level} | HP: {self.hp}/{self.max_hp} | ATK: {self.attack}")
    
    def attack_enemy(self, enemy):
        """Скилл: Атаковать врага"""
        damage = self.attack
        enemy.hp -= damage
        print(f"⚔️ {self.name} атакует {enemy.name} и наносит {damage} урона!")
        if enemy.hp <= 0:
            print(f"💀 {enemy.name} повержен!")
        else:
            print(f"🩸 У {enemy.name} осталось {enemy.hp} HP")
    
    def heal(self, amount):
        """Скилл: Лечиться"""
        self.hp = min(self.hp + amount, self.max_hp)
        print(f"💚 {self.name} восстановил {amount} HP. Теперь HP: {self.hp}")
    
    def gain_xp(self, amount):
        """Скилл: Получить опыт"""
        self.xp += amount
        print(f"⭐ {self.name} получил {amount} XP! Всего: {self.xp}")
        
        # Проверка уровня
        if self.xp >= 100:
            self.level_up()
    
    def level_up(self):
        """Скилл: Повысить уровень"""
        self.level += 1
        self.max_hp += 20
        self.hp = self.max_hp
        self.attack += 5
        self.xp = 0
        print(f"🎉 {self.name} достиг {self.level} уровня! HP и ATK выросли!")

# Создаём героев
warrior = Hero("Конан", 150, 25)
goblin = Hero("Гоблин", 50, 10)

# Битва!
warrior.show_stats()
goblin.show_stats()

warrior.attack_enemy(goblin)  # ⚔️ Конан атакует Гоблина...
warrior.gain_xp(50)           # ⭐ Получаем опыт
warrior.gain_xp(60)           # 🎉 Уровень повышен!
📚 Лор для гиков То, что ты только что написал — это основа любой RPG. Именно так устроены классы в World of Warcraft, Skyrim, Dota 2. У каждого юнита есть атрибуты (HP, мана, урон) и методы (атака, скилл, смерть). Теперь ты понимаешь, как устроены твои любимые игры изнутри!

📝 Задание

Создай класс Pet с:

  • Атрибутами: имя, голод (0-100), счастье (0-100), энергия (0-100)
  • Методами: feed() (уменьшает голод), play() (увеличивает счастье, уменьшает энергию), sleep() (восстанавливает энергию)
  • Методом status(), который выводит текущее состояние питомца
class Pet:
    def __init__(self, name):
        self.name = name
        self.hunger = 50      # 0 = сыт, 100 = голоден
        self.happiness = 50   # 0 = грустит, 100 = счастлив
        self.energy = 50      # 0 = устал, 100 = полон сил
    
    def feed(self):
        self.hunger = max(0, self.hunger - 30)
        print(f"🍕 {self.name} поел! Голод: {self.hunger}")
    
    def play(self):
        if self.energy < 20:
            print(f"😴 {self.name} слишком устал, чтобы играть!")
            return
        self.happiness = min(100, self.happiness + 20)
        self.energy = max(0, self.energy - 20)
        print(f"🎾 {self.name} поиграл! Счастье: {self.happiness}, Энергия: {self.energy}")
    
    def sleep(self):
        self.energy = min(100, self.energy + 40)
        print(f"💤 {self.name} поспал. Энергия: {self.energy}")
    
    def status(self):
        print(f"\n🐾 {self.name}:")
        print(f"   🍖 Голод: {self.hunger}/100")
        print(f"   😊 Счастье: {self.happiness}/100")
        print(f"   ⚡ Энергия: {self.energy}/100\n")

# Создаём питомца

🧬 Эволюция: Наследование

Создаём новые классы на основе старых
+80 XP

В играх есть эволюция: покемон превращается в более сильную версию, сохраняя все свои статы, но получая новые скиллы. В Python это называется наследование.

🧬
Покемон-стиль Представь: у тебя есть класс Character (базовый). От него наследуются Warrior, Mage, Archer. Все они получают общие атрибуты (имя, HP), но у каждого свои уникальные скиллы. Это как эволюция в Pokémon — базовые характеристики остаются, но добавляются новые способности.

📝 Создаём классы-наследники

class Character:
    """Базовый класс — как базовый покемон"""
    def __init__(self, name, hp):
        self.name = name
        self.hp = hp
    
    def show(self):
        print(f"{self.name} | HP: {self.hp}")

class Warrior(Character):
    """Наследует от Character, но добавляет своё"""
    def __init__(self, name, hp, sword_power):
        super().__init__(name, hp)  # Вызываем конструктор родителя
        self.sword_power = sword_power
    
    def slash(self):
        print(f"⚔️ {self.name} делает мощный удар мечом! Урон: {self.sword_power}")

class Mage(Character):
    def __init__(self, name, hp, mana, spell_power):
        super().__init__(name, hp)
        self.mana = mana
        self.spell_power = spell_power
    
    def cast_fireball(self):
        if self.mana >= 20:
            self.mana -= 20
            print(f"🔥 {self.name} кастует Огненный шар! Урон: {self.spell_power}")
        else:
            print(f"😵 У {self.name} недостаточно маны!")

# Создаём персонажей
conan = Warrior("Конан", 150, 35)
gandalf = Mage("Гэндальф", 80, 100, 50)

conan.show()        # Конан | HP: 150
conan.slash()       # ⚔️ Конан делает мощный удар мечом! Урон: 35

gandalf.show()      # Гэндальф | HP: 80
gandalf.cast_fireball()  # 🔥 Гэндальф кастует Огненный шар! Урон: 50
💡 Магия super() super().__init__(name, hp) — это как сказать: «Папа-класс, сделай свою работу по инициализации имени и HP, а я уже добавлю свои фишки». Без этой строки у воина не было бы имени и HP — только сила меча.

📝 Финальный код: Битва героев

# ==========================================
# ⚔️ БИТВА ГЕРОЕВ — МИНИ-RPG
# Автор: [твоё имя]
# ==========================================

import random
import time

class Character:
    """Базовый класс персонажа"""
    def __init__(self, name, hp, attack):
        self.name = name
        self.hp = hp
        self.max_hp = hp
        self.attack = attack
    
    def is_alive(self):
        return self.hp > 0
    
    def take_damage(self, damage):
        self.hp = max(0, self.hp - damage)
    
    def show(self):
        hp_bar = "█" * (self.hp // 10) + "░" * ((self.max_hp - self.hp) // 10)
        print(f"{self.name}: [{hp_bar}] {self.hp}/{self.max_hp} HP")

class Warrior(Character):
    def __init__(self, name):
        super().__init__(name, hp=150, attack=20)
        self.shield_block = 0.2  # 20% шанс заблокировать удар
    
    def attack(self, enemy):
        damage = self.attack + random.randint(-5, 10)
        enemy.take_damage(damage)
        print(f"⚔️ {self.name} атакует {enemy.name} на {damage} урона!")
    
    def defend(self):
        if random.random() < self.shield_block:
            print(f"🛡️ {self.name} блокирует удар щитом!")
            return True
        return False

class Mage(Character):
    def __init__(self, name):
        super().__init__(name, hp=90, attack=15)
        self.mana = 100
        self.max_mana = 100
    
    def attack(self, enemy):
        if self.mana >= 30:
            damage = 40 + random.randint(0, 15)
            self.mana -= 30
            enemy.take_damage(damage)
            print(f"🔥 {self.name} кастует огненный шар на {damage} урона!")
        else:
            damage = self.attack
            enemy.take_damage(damage)
            print(f"✨ {self.name} бьёт посохом на {damage} урона (мало маны)")
    
    def meditate(self):
        self.mana = min(self.max_mana, self.mana + 40)
        print(f"🧘 {self.name} медитирует. Мана: {self.mana}/{self.max_mana}")

def battle(hero1, hero2):
    """Главный цикл битвы"""
    print("=" * 50)
    print(f"🎬 НАЧИНАЕТСЯ БИТВА: {hero1.name} VS {hero2.name}")
    print("=" * 50)
    
    round_num = 1
    while hero1.is_alive() and hero2.is_alive():
        print(f"\n--- Раунд {round_num} ---")
        hero1.show()
        hero2.show()
        time.sleep(1)
        
        # Ход первого героя
        attacker, defender = hero1, hero2
        if hasattr(defender, 'defend') and defender.defend():
            print(f"🛡️ Атака заблокирована!")
        else:
            attacker.attack(defender)
        
        if not defender.is_alive():
            break
        
        time.sleep(1)
        
        # Ход второго героя
        attacker, defender = hero2, hero1
        if hasattr(defender, 'defend') and defender.defend():
            print(f"🛡️ Атака заблокирована!")
        else:
            attacker.attack(defender)
        
        # Медитация мага, если маны мало
        if isinstance(hero2, Mage) and hero2.mana < 30:
            hero2.meditate()
        
        round_num += 1
        time.sleep(1)
    
    # Определяем победителя
    print("\n" + "=" * 50)
    if hero1.is_alive():
        print(f"🏆 ПОБЕДИТЕЛЬ: {hero1.name}!")
    else:
        print(f"🏆 ПОБЕДИТЕЛЬ: {hero2.name}!")
    print("=" * 50)

# Создаём героев
conan = Warrior("Конан-Варвар")
gandalf = Mage("Гэндальф-Серый")

# Битва!
battle(conan, gandalf)
