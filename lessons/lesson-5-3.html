Что такое API?

Как программы общаются друг с другом
+100 XP

API (Application Programming Interface) — это набор правил, по которым одна программа может общаться с другой. Когда ты используешь ChatGPT в браузере, твой браузер отправляет запрос на сервер OpenAI через API и получает ответ.

🍽️
Игровая аналогия API — это как официант в ресторане. Ты (клиент) не идешь на кухню готовить сам. Ты говоришь официанту (API) что хочешь, он передает заказ повару (серверу), и приносит тебе готовое блюдо (ответ). Ты не знаешь, как именно повар готовил — тебе важен только результат!

🤖 OpenAI API

Подключение к GPT-4 и ChatGPT
+200 XP

OpenAI предоставляет API для доступа к моделям GPT-4, GPT-3.5 и другим. Чтобы использовать API, нужно зарегистрироваться на platform.openai.com, получить API-ключ и установить библиотеку openai.

📝 Первый запрос к OpenAI

import os
from openai import OpenAI

# Initialize client with API key from environment variable
# NEVER hardcode your API key in the source code!
client = OpenAI(api_key=os.getenv('OPENAI_API_KEY'))

# Send a chat completion request
response = client.chat.completions.create(
    model="gpt-4o-mini",  # Cost-effective model
    messages=[
        {"role": "system", "content": "You are a helpful assistant."},
        {"role": "user", "content": "Explain what a neural network is in one sentence."}
    ],
    temperature=0.7,  # Controls randomness (0 = deterministic, 1 = creative)
    max_tokens=100    # Maximum length of response
)

# Extract and print the response
answer = response.choices[0].message.content
print(f"OpenAI Response: {answer}")

# Check token usage
usage = response.usage
print(f"Tokens used: {usage.prompt_tokens} input, {usage.completion_tokens} output")
⚠️ Безопасность API-ключей НИКОГДА не публикуй API-ключи в коде или на GitHub! Используй переменные окружения (.env файл) и добавь .env в .gitignore. Если ключ утечет — его нужно немедленно отозвать в настройках OpenAI.

🇷🇺 YandexGPT API

Российская языковая модель
+200 XP

YandexGPT — это российская языковая модель от Яндекса. Она хорошо работает с русским языком и доступна через Yandex Cloud. API использует формат, похожий на OpenAI, но с некоторыми отличиями в аутентификации.

📝 Запрос к YandexGPT

import os
import requests

# YandexGPT API configuration
FOLDER_ID = os.getenv('YANDEX_FOLDER_ID')
IAM_TOKEN = os.getenv('YANDEX_IAM_TOKEN')

# API endpoint for YandexGPT
url = "https://llm.api.cloud.yandex.net/foundationModels/v1/completion"

# Request headers with authentication
headers = {
    "Content-Type": "application/json",
    "Authorization": f"Bearer {IAM_TOKEN}",
    "x-folder-id": FOLDER_ID
}

# Request body
payload = {
    "modelUri": f"gpt://{FOLDER_ID}/yandexgpt/latest",
    "completionOptions": {
        "stream": False,
        "temperature": 0.6,
        "maxTokens": "100"
    },
    "messages": [
        {
            "role": "system",
            "text": "Ты полезный ассистент."
        },
        {
            "role": "user",
            "text": "Объясни, что такое нейронная сеть, одним предложением."
        }
    ]
}

# Send request
response = requests.post(url, headers=headers, json=payload)
result = response.json()

# Extract answer
answer = result['result']['alternatives'][0]['message']['text']
print(f"YandexGPT Response: {answer}")

# Check token usage
usage = result['result']['usage']
print(f"Tokens: {usage['inputTextTokens']} input, {usage['completionTokens']} output")
💡 Зачем нужен YandexGPT? YandexGPT лучше понимает русский язык и культурный контекст. Он также соответствует российскому законодательству о хранении данных, что важно для корпоративных проектов в России.

🏠 Ollama: Локальные модели

Запуск LLM на своем компьютере
+250 XP

Ollama позволяет запускать большие языковые модели локально на твоем компьютере. Это бесплатно, приватно (данные не уходят в облако) и работает без интернета! Популярные модели: Llama 3, Mistral, Phi-3.

📝 Установка и использование Ollama

# Step 1: Install Ollama from https://ollama.com
# Step 2: Download a model (run in terminal)
# ollama pull llama3.2:1b  # Small model for testing
# ollama pull mistral       # More capable model

# Step 3: Use Ollama API in Python
import requests

# Ollama runs a local server on port 11434
url = "http://localhost:11434/api/generate"

payload = {
    "model": "llama3.2:1b",  # Use downloaded model
    "prompt": "Explain what a neural network is in one sentence.",
    "stream": False,
    "options": {
        "temperature": 0.7,
        "num_predict": 100
    }
}

# Send request to local Ollama server
response = requests.post(url, json=payload)
result = response.json()

# Extract response
answer = result['response']
print(f"Ollama Response: {answer}")

# Check token stats
print(f"Tokens: {result.get('prompt_eval_count', 0)} input, {result.get('eval_count', 0)} output")
print(f"Time: {result.get('total_duration', 0) / 1e9:.2f} seconds")
📚 Почему локальные модели важны? 1) Приватность: данные не покидают твой компьютер
2) Бесплатно: нет платы за токены
3) Без интернета: работает офлайн
4) Кастомизация: можно дообучить под свои задачи
Минус: требует мощный GPU для больших моделей.

🔀 Универсальный интерфейс

Абстракция над разными API
+250 XP

Каждый API имеет свой формат запросов. Чтобы не писать разный код для каждого провайдера, создадим универсальный интерфейс — один класс, который может работать с OpenAI, YandexGPT и Ollama через единый API.

📝 Класс LLMRouter

from abc import ABC, abstractmethod
import os
import requests
from openai import OpenAI

class BaseLLM(ABC):
    """Abstract base class for all LLM providers"""
    
    @abstractmethod
    def chat(self, messages: list, **kwargs) -> str:
        """Send chat messages and return response"""
        pass

class OpenAILLM(BaseLLM):
    """OpenAI API implementation"""
    
    def __init__(self, model="gpt-4o-mini"):
        self.client = OpenAI(api_key=os.getenv('OPENAI_API_KEY'))
        self.model = model
    
    def chat(self, messages, **kwargs):
        response = self.client.chat.completions.create(
            model=self.model,
            messages=messages,
            **kwargs
        )
        return response.choices[0].message.content

class YandexLLM(BaseLLM):
    """YandexGPT API implementation"""
    
    def __init__(self, folder_id=None, iam_token=None):
        self.folder_id = folder_id or os.getenv('YANDEX_FOLDER_ID')
        self.iam_token = iam_token or os.getenv('YANDEX_IAM_TOKEN')
        self.url = "https://llm.api.cloud.yandex.net/foundationModels/v1/completion"
    
    def chat(self, messages, **kwargs):
        headers = {
            "Content-Type": "application/json",
            "Authorization": f"Bearer {self.iam_token}",
            "x-folder-id": self.folder_id
        }
        
        payload = {
            "modelUri": f"gpt://{self.folder_id}/yandexgpt/latest",
            "completionOptions": {"stream": False, "temperature": 0.6, "maxTokens": "500"},
            "messages": [{"role": m["role"], "text": m["content"]} for m in messages]
        }
        
        response = requests.post(self.url, headers=headers, json=payload)
        return response.json()['result']['alternatives'][0]['message']['text']

class OllamaLLM(BaseLLM):
    """Ollama local model implementation"""
    
    def __init__(self, model="llama3.2:1b"):
        self.model = model
        self.url = "http://localhost:11434/api/chat"
    
    def chat(self, messages, **kwargs):
        payload = {
            "model": self.model,
            "messages": messages,
            "stream": False
        }
        
        response = requests.post(self.url, json=payload)
        return response.json()['message']['content']

# Usage example
def get_llm(provider="openai"):
    """Factory function to create LLM instance"""
    providers = {
        "openai": OpenAILLM,
        "yandex": YandexLLM,
        "ollama": OllamaLLM
    }
    return providers[provider]()

# Test all providers
messages = [{"role": "user", "content": "What is 2+2?"}]

for provider in ["openai", "yandex", "ollama"]:
    try:
        llm = get_llm(provider)
        answer = llm.chat(messages)
        print(f"{provider}: {answer}")
    except Exception as e:
        print(f"{provider}: Error - {e}")
💡 Паттерн "Стратегия" Этот код использует паттерн проектирования "Стратегия" (Strategy Pattern). Все провайдеры реализуют один интерфейс BaseLLM, поэтому код, использующий LLM, не зависит от конкретного провайдера. Можно легко переключаться между ними!

Приложение с выбором модели
+500 XP
💬 Пришло время создать полноценное чат-приложение, где пользователь может выбирать между OpenAI, YandexGPT и локальной моделью! Это реальный проект, который можно показать в портфолио.

📝 Полный код чат-приложения

import os
import sys
from datetime import datetime

# Import our universal LLM classes (from Level 4)
from llm_providers import OpenAILLM, YandexLLM, OllamaLLM

class ChatApp:
    """Multi-provider chat application"""
    
    def __init__(self):
        self.providers = {
            "1": ("OpenAI GPT-4o-mini", OpenAILLM()),
            "2": ("YandexGPT", YandexLLM()),
            "3": ("Ollama Llama 3.2", OllamaLLM("llama3.2:1b"))
        }
        self.current_provider = None
        self.history = []
    
    def select_provider(self):
        """Let user choose LLM provider"""
        print("\n=== Select AI Provider ===")
        for key, (name, _) in self.providers.items():
            print(f"{key}. {name}")
        
        choice = input("\nEnter choice (1-3): ")
        if choice in self.providers:
            self.current_provider = self.providers[choice][1]
            print(f"✓ Selected: {self.providers[choice][0]}")
        else:
            print("Invalid choice. Using OpenAI by default.")
            self.current_provider = self.providers["1"][1]
    
    def chat(self, user_message):
        """Send message and get response"""
        if not self.current_provider:
            self.select_provider()
        
        # Add user message to history
        self.history.append({"role": "user", "content": user_message})
        
        try:
            # Get response from selected provider
            response = self.current_provider.chat(self.history)
            
            # Add assistant response to history
            self.history.append({"role": "assistant", "content": response})
            
            return response
        except Exception as e:
            return f"Error: {str(e)}"
    
    def save_conversation(self, filename="chat_log.txt"):
        """Save conversation history to file"""
        with open(filename, "w", encoding="utf-8") as f:
            f.write(f"Chat Log - {datetime.now()}\n")
            f.write("=" * 50 + "\n\n")
            
            for msg in self.history:
                role = msg["role"].upper()
                content = msg["content"]
                f.write(f"[{role}]: {content}\n\n")
        
        print(f"✓ Conversation saved to {filename}")
    
    def run(self):
        """Main chat loop"""
        print("🤖 Welcome to Multi-Provider Chat!")
        print("Type 'quit' to exit, 'provider' to change AI, 'save' to save chat\n")
        
        self.select_provider()
        
        while True:
            user_input = input("\nYou: ").strip()
            
            if user_input.lower() == 'quit':
                print("Goodbye! 👋")
                break
            elif user_input.lower() == 'provider':
                self.select_provider()
                continue
            elif user_input.lower() == 'save':
                self.save_conversation()
                continue
            elif not user_input:
                continue
            
            print("\nAI is thinking...")
            response = self.chat(user_input)
            print(f"\nAssistant: {response}")

# Run the application
if __name__ == "__main__":
    app = ChatApp()
    app.run()
