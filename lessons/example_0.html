📝 Часть 1: Регистрация на GitHub

Шаг 1: Создаём аккаунт

1 Открой браузер и перейди на сайт github.com
2 Нажми кнопку "Sign up" (Зарегистрироваться) в правом верхнем углу
3 Введи свой email (можно использовать школьную почту)
4 Придумай пароль (минимум 8 символов, буквы + цифры)
5 Нажми "Create account"

Шаг 2: Подтверждение почты

  1. Открой свою почту
  2. Найди письмо от GitHub (проверь папку "Спам", если не видишь)
  3. Нажми на ссылку подтверждения в письме
  4. Вернись на GitHub — ты увидишь страницу с проверкой

Шаг 3: Завершение регистрации

  1. GitHub может попросить решить простую задачу (капча) — это защита от роботов
  2. Выбери план Free (бесплатный) — его достаточно для учёбы
  3. Готово! Ты попал на свою главную страницу GitHub

🔧 Часть 2: Установка Git

Что такое Git?

Git — это программа, которая сохраняет все изменения в твоём коде. Как "машина времени" для файлов.

Установка на Windows:

1 Перейди на сайт git-scm.com
2 Нажми "Download for Windows"
3 Запусти скачанный файл .exe
4 Нажимай "Next" на всех экранах (настройки по умолчанию подходят)
5 В конце нажми "Install", затем "Finish"

Установка на Mac:

1 Открой Terminal (нажми Cmd + Space, введи "Terminal")
2 Введи команду:
git --version
3 Если Git не установлен, система сама предложит его установить — нажми "Install"

Проверка установки:

Открой Командную строку (Windows) или Terminal (Mac) и введи:

git --version

Должно появиться что-то вроде: git version 2.40.0

️ Часть 3: Настройка Git (первый запуск)

Открой Командную строку или Terminal и выполни две команды:

git config --global user.name "Твоё Имя"
git config --global user.email "твой@email.com"
⚠️ Важно: Используй тот же email, что и при регистрации на GitHub!

Проверь настройки:

git config --list

🔗 Часть 4: Подключение VS Code к GitHub

Способ 1: Через браузер (проще)

1 Открой VS Code
2 Нажми на иконку человечка слева внизу (Accounts)
3 Выбери "Sign in with GitHub"
4 Откроется браузер — войди в свой аккаунт GitHub
5 Разреши VS Code доступ к твоему аккаунту
6 Вернись в VS Code — ты увидишь свой никнейм

Способ 2: Через терминал

В терминале VS Code (Ctrl + ~) введи:

git config --global credential.helper store

При первом пуше Git запомнит твой пароль.

📥 Часть 5: Получаем репозиторий учителя

Шаг 1: Форк репозитория

1 Учитель даст тебе ссылку на репозиторий курса (например: https://github.com/teacher/ai-course)
2 Открой эту ссылку в браузере
3 В правом верхнем углу нажми кнопку "Fork"
4 Выбери свой аккаунт — создастся копия репозитория у тебя

Шаг 2: Клонируем репозиторий на компьютер

1 Открой VS Code
2 Нажми Ctrl + Shift + P (Windows) или Cmd + Shift + P (Mac)
3 Введи: Git: Clone
4 Вставь ссылку на свой форкнутый репозиторий (например: https://github.com/твой-ник/ai-course)
5 Выбери папку, куда сохранить проект
6 VS Code спросит "Open the repository?" — нажми "Open"

📤 Часть 6: Отправка первой работы

Шаг 1: Создаём ветку

1 В VS Code открой терминал: Ctrl + ~
2 Введи команду:
git checkout -b lesson-1.1
Это создаст новую ветку для твоего урока.

Шаг 2: Выполняем задание

1 Найди папку с заданием (например: lessons/lesson-1.1/)
2 Открой файл задания (например: task.py или README.md)
3 Выполни задание — напиши код или ответь на вопросы
4 Сохрани файл: Ctrl + S

Шаг 3: Проверяем изменения

1 В VS Code нажми на иконку ветки слева (Source Control) или Ctrl + Shift + G
2 Ты увидишь список изменённых файлов
3 Нажми на файл — VS Code покажет, что ты изменил (красным — удалено, зелёным — добавлено)

Шаг 4: Делаем коммит

1 В поле "Message" напиши описание: Выполнен урок 1.1: Синтаксис Python
2 Нажми кнопку "Commit" (или Ctrl + Enter)

Шаг 5: Отправляем на GitHub

В терминале введи:

git push origin lesson-1.1
⚠️ Если Git спросит логин и пароль:
Логин: твой никнейм на GitHub
Пароль: не пароль от GitHub, а персональный токен (см. раздел ниже)

🔄 Часть 7: Создаём Pull Request

Шаг 1: Открываем GitHub

1 Перейди на свой репозиторий на GitHub
2 Ты увидишь уведомление: "lesson-1.1 had recent pushes" с кнопкой "Compare & pull request"
3 Нажми эту кнопку

Шаг 2: Заполняем PR

1 Title (заголовок): Урок 1.1: Синтаксис Python — [Твоё Имя]
2 Description (описание): Напиши, что ты сделал, какие были трудности
3 Убедись, что стрелка идёт от твоей ветки к ветке учителя: твой-ник:lesson-1.1 → teacher:main
4 Нажми "Create pull request"

Шаг 3: Ждём проверку

  1. Учитель получит уведомление о твоём PR
  2. Он проверит код и оставит комментарии
  3. Если нужно что-то исправить — внеси изменения, сделай коммит и пуш — PR обновится автоматически
  4. Когда всё хорошо, учитель нажмёт "Merge" — твоя работа принята! 🎉

Персональный токен GitHub

GitHub больше не принимает обычные пароли. Нужно создать токен:

1 На GitHub нажми на свою аватарку → Settings
2 Слева внизу: Developer settings → Personal access tokens → Tokens (classic)
3 Нажми "Generate new token"
4 Дай название: VS Code
5 Выбери срок действия (например, 90 дней)
6 Поставь галочку напротив repo (полный доступ к репозиториям)
7 Нажми "Generate token"
8 Скопируй токен (он показывается только один раз!)
9 Вставь его вместо пароля, когда Git попросит

Шпаргалка команд

Команда Что делает
git clone [ссылка] Скачивает репозиторий на компьютер
git checkout -b [название] Создаёт новую ветку
git status Показывает изменённые файлы
git add . Добавляет все изменения для коммита
git commit -m "текст" Сохраняет изменения с описанием
git push origin [ветка] Отправляет изменения на GitHub
git pull origin main Скачивает обновления от учителя

🆘 Частые проблемы

Проблема: "Permission denied" при пуше

Решение: Убедись, что ты работаешь со своим форком, а не с репозиторием учителя.

Проблема: "Merge conflict"

Решение: Учитель обновил репозиторий, пока ты работал. Сделай:
git pull origin main
Исправь конфликты в файлах (VS Code покажет их), затем снова сделай коммит и пуш.

Проблема: Забыл создать ветку и работаю в main

Решение:
git checkout -b lesson-1.1
git push origin lesson-1.1

✅ Чеклист перед отправкой работы

  • Создал ветку для урока
  • Выполнил задание полностью
  • Сохранил все файлы
  • Сделал коммит с понятным описанием
  • Отправил изменения на GitHub (git push)
  • Создал Pull Request
  • Написал описание PR (что сделал, какие были сложности)
💡 Совет: Не бойся задавать вопросы учителю в комментариях к PR! GitHub — это место для обучения, а не для идеального кода с первого раза.

📝 Part 1: GitHub Registration

Step 1: Create an account

1 Open your browser and go to github.com
2 Click the "Sign up" button in the top right corner
3 Enter your email (you can use your school email)
4 Create a password (minimum 8 characters, letters + numbers)
5 Click "Create account"

Step 2: Email verification

  1. Open your email
  2. Find the email from GitHub (check "Spam" folder if you don't see it)
  3. Click the confirmation link in the email
  4. Return to GitHub — you'll see a verification page

Step 3: Complete registration

  1. GitHub may ask you to solve a simple task (captcha) — this is bot protection
  2. Choose the Free plan — it's enough for studying
  3. Done! You're now on your GitHub homepage

🔧 Part 2: Installing Git

What is Git?

Git is a program that saves all changes to your code. Like a "time machine" for files.

Installation on Windows:

1 Go to git-scm.com
2 Click "Download for Windows"
3 Run the downloaded .exe file
4 Click "Next" on all screens (default settings are fine)
5 At the end, click "Install", then "Finish"

Installation on Mac:

1 Open Terminal (press Cmd + Space, type "Terminal")
2 Enter the command:
git --version
3 If Git is not installed, the system will offer to install it — click "Install"

Checking installation:

Open Command Prompt (Windows) or Terminal (Mac) and enter:

git --version

You should see something like: git version 2.40.0

⚙️ Part 3: Git Configuration (first launch)

Open Command Prompt or Terminal and run two commands:

git config --global user.name "Your Name"
git config --global user.email "your@email.com"
️ Important: Use the same email you used for GitHub registration!

Check your settings:

git config --list

Part 4: Connecting VS Code to GitHub

Method 1: Via browser (easier)

1 Open VS Code
2 Click the person icon at the bottom left (Accounts)
3 Select "Sign in with GitHub"
4 A browser will open — log in to your GitHub account
5 Allow VS Code to access your account
6 Return to VS Code — you'll see your username

Method 2: Via terminal

In VS Code terminal (Ctrl + ~) enter:

git config --global credential.helper store

Git will remember your password on the first push.

📥 Part 5: Getting the teacher's repository

Step 1: Fork the repository

1 The teacher will give you a link to the course repository (e.g., https://github.com/teacher/ai-course)
2 Open this link in your browser
3 In the top right corner, click the "Fork" button
4 Select your account — a copy of the repository will be created in your account

Step 2: Clone the repository to your computer

1 Open VS Code
2 Press Ctrl + Shift + P (Windows) or Cmd + Shift + P (Mac)
3 Type: Git: Clone
4 Paste the link to your forked repository (e.g., https://github.com/your-username/ai-course)
5 Choose a folder to save the project
6 VS Code will ask "Open the repository?" — click "Open"

📤 Part 6: Submitting your first assignment

Step 1: Create a branch

1 In VS Code, open the terminal: Ctrl + ~
2 Enter the command:
git checkout -b lesson-1.1
This will create a new branch for your lesson.

Step 2: Complete the assignment

1 Find the assignment folder (e.g., lessons/lesson-1.1/)
2 Open the assignment file (e.g., task.py or README.md)
3 Complete the assignment — write code or answer questions
4 Save the file: Ctrl + S

Step 3: Check changes

1 In VS Code, click the branch icon on the left (Source Control) or press Ctrl + Shift + G
2 You'll see a list of changed files
3 Click on a file — VS Code will show what you changed (red — deleted, green — added)

Step 4: Make a commit

1 In the "Message" field, write a description: Completed lesson 1.1: Python Syntax
2 Click the "Commit" button (or Ctrl + Enter)

Step 5: Push to GitHub

In the terminal, enter:

git push origin lesson-1.1
⚠️ If Git asks for login and password:
Login: your GitHub username
Password: not your GitHub password, but a personal token (see section below)

🔄 Part 7: Creating a Pull Request

Step 1: Open GitHub

1 Go to your repository on GitHub
2 You'll see a notification: "lesson-1.1 had recent pushes" with a "Compare & pull request" button
3 Click this button

Step 2: Fill in the PR

1 Title: Lesson 1.1: Python Syntax — [Your Name]
2 Description: Write what you did, what difficulties you had
3 Make sure the arrow goes from your branch to the teacher's branch: your-username:lesson-1.1 → teacher:main
4 Click "Create pull request"

Step 3: Wait for review

  1. The teacher will receive a notification about your PR
  2. They will review the code and leave comments
  3. If something needs to be fixed — make changes, commit and push — the PR will update automatically
  4. When everything is good, the teacher will click "Merge" — your work is accepted! 🎉

🔐 GitHub Personal Token

GitHub no longer accepts regular passwords. You need to create a token:

1 On GitHub, click your avatar → Settings
2 At the bottom left: Developer settings → Personal access tokens → Tokens (classic)
3 Click "Generate new token"
4 Give it a name: VS Code
5 Choose expiration period (e.g., 90 days)
6 Check the box next to repo (full access to repositories)
7 Click "Generate token"
8 Copy the token (it's shown only once!)
9 Paste it instead of the password when Git asks

git checkout -b [name] Creates a new branch
git status Shows changed files
git add . Adds all changes for commit
git commit -m "text" Saves changes with description

🆘 Common Problems

Problem: "Permission denied" when pushing

Solution: Make sure you're working with your fork, not the teacher's repository.

Problem: "Merge conflict"

Solution: The teacher updated the repository while you were working. Do:
git pull origin main
Fix conflicts in files (VS Code will show them), then commit and push again.

Problem: Forgot to create a branch and working in main

Solution:
git checkout -b lesson-1.1
git push origin lesson-1.1

✅ Checklist before submitting work

  • Created a branch for the lesson
  • Completed the assignment fully
  • Saved all files
  • Made a commit with a clear description
  • Pushed changes to GitHub (git push)
  • Created a Pull Request
  • Wrote a PR description (what you did, what difficulties you had)
💡 Tip: Don't be afraid to ask the teacher questions in PR comments! GitHub is a place for learning, not for perfect code on the first try.
