📊 Что такое DataFrame?

Твоя первая таблица в коде
+50 XP

В Pandas главная структура данных называется DataFrame. Представь себе таблицу Excel или инвентарь в RPG-игре: у неё есть строки (герои) и столбцы (их характеристики: Имя, HP, Класс).

🎒
Игровая аналогия DataFrame — это как экран инвентаря в игре. Ты можешь сортировать предметы по типу, фильтровать по редкости или искать конкретный меч. Pandas делает то же самое с данными, но в миллионы раз быстрее Excel.

📝 Создаём первый DataFrame

import pandas as pd

# Creating a dictionary of game characters
data = {
    "Name": ["Alya", "Bolat", "Dima", "Eva"],
    "Class": ["Mage", "Warrior", "Archer", "Healer"],
    "HP": [80, 150, 100, 90],
    "Level": [15, 20, 12, 18]
}

# Converting the dictionary into a DataFrame
df = pd.DataFrame(data)

print(df)

📂 Загрузка данных из файла

Открываем сундук с данными
+80 XP

В реальной жизни Data Scientist'ы не вводят данные вручную. Они загружают их из файлов. Самый популярный формат — CSV (Comma-Separated Values). Это просто текстовый файл, где значения разделены запятыми.

📝 Чтение CSV файла

# Load the dataset from a CSV file
# Imagine this file contains stats of 1000 game monsters
df_monsters = pd.read_csv("monsters.csv")

# Display the first 5 rows to check if it loaded correctly
print(df_monsters.head())
⚠️ Частая ошибка новичков Убедись, что файл monsters.csv лежит в той же папке, что и твой Python-скрипт. Иначе Pandas выдаст ошибку FileNotFoundError (как будто сундук заперт или его нет).

🔍 Инспекция данных

Сканируем противника перед боем
+100 XP

Прежде чем анализировать данные, нужно понять, с чем ты имеешь дело. Сколько всего строк? Есть ли пропущенные значения (NaN)? Какие типы данных в столбцах?

📝 Инструменты инспектора

# Get the dimensions of the DataFrame (rows, columns)
print("Shape:", df_monsters.shape)

# Get a quick statistical summary of numeric columns
# Shows min, max, mean, and standard deviation
print("\nStats:")
print(df_monsters.describe())

# Check for missing values in each column
print("\nMissing values:")
print(df_monsters.isnull().sum())
📚 Лор для гиков Метод .describe() — это как заклинание «Анализ» в RPG. Он мгновенно рассказывает всё о числовых характеристиках твоего датасета, экономя часы ручной проверки.

⚔️ Фильтрация и сортировка

Находим нужный лут в инвентаре
+120 XP

Самая частая задача: найти данные, которые соответствуют определённым условиям. Например, «покажи только тех монстров, у которых уровень атаки больше 50».

📝 Магия фильтрации

# Filter: Show only monsters with HP greater than 100
strong_monsters = df_monsters[df_monsters["HP"] > 100]
print(strong_monsters)

# Sort: Order the DataFrame by Attack power, descending
sorted_monsters = df_monsters.sort_values(by="Attack", ascending=False)
print(sorted_monsters.head(3)) # Top 3 strongest monsters
🧙‍♂️✨ В Excel для этого нужно тыкать мышкой 10 минут. В Pandas это одна строка кода, которая выполняется за миллисекунды даже на миллионе строк.

👑📊 Ты знаешь, как загружать, изучать и фильтровать данные. Пришло время объединить всё это в одном мощном скрипте!

📝 Финальный код: Поиск легендарного предмета

import pandas as pd

# 1. Load the data
df_items = pd.read_csv("game_loot.csv")

# 2. Inspect: How many items do we have?
print(f"Total items in database: {df_items.shape[0]}")

# 3. Filter: Find legendary items (Rarity == 'Legendary')
legendary_items = df_items[df_items["Rarity"] == "Legendary"]

# 4. Sort: Find the one with the highest damage
best_item = legendary_items.sort_values(by="Damage", ascending=False).iloc[0]

# 5. Output the result
print("\n🏆 THE BEST LEGENDARY ITEM FOUND:")
print(f"Name: {best_item['Name']}")
print(f"Damage: {best_item['Damage']}")
print(f"Description: {best_item['Description']}")
🚨 Проверь перед сдачей босса Скрипт запустился? Он нашёл и вывел название самого мощного легендарного предмета? Поздравляю — ты полноценно проанализировал датасет! 🏆
