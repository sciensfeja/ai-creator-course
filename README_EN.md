#  Artificial Intelligence and Machine Learning Course

> From Python to LLMs — a complete journey into the world of AI with hands-on practice on GitHub

## 📋 About the Course

This course will take you from the basics of Python to building your own projects using neural networks, computer vision, and large language models. All practical assignments are completed through **GitHub** — you will learn to work and collaborate like a professional developer.

## 🛠 Practice via GitHub

All practical work in this course is done on the **GitHub** platform. It's not just a place to store code — it's the industry-standard tool used by professional developers and teams worldwide.

### What you will master:

- ✅ **Git** — Version control system: how to save code changes and roll back if needed
- ✅ **GitHub** — Platform for storing and collaborating on code
- ✅ **Pull Request (PR)** — The system for submitting your assignments to the instructor
- ✅ **Code Review** — The process of having your code reviewed by the instructor with detailed feedback
- ✅ **Branching** — Working on tasks without risking breaking the main codebase
- ✅ **Teamwork** — Collaborative development of a single project with multiple contributors

---

## 📤 How to Submit Assignments

The homework submission system works through **Pull Requests (PR)** — a standard mechanism in software development where you propose your code changes for review.

### Step-by-step process:

```text
1. Fork the course repository
        ↓
2. Create a branch for your lesson (e.g., lesson-1.1)
        ↓
3. Complete the assignment and commit your changes
        ↓
4. Open a Pull Request to the main repository
        ↓
5. The instructor will conduct a Code Review and leave comments
        ↓
6. Make corrections (if needed) and get approved ✅
